# Применение в линейной алгебре

Умножение матриц — краеугольный камень линейной алгебры. Без него невозможно описать большинство процессов, связанных с линейными преобразованиями.

## Линейные преобразования

Любое линейное преобразование пространства — поворот, масштабирование, отражение, сдвиг — описывается матрицей. Композиция двух преобразований эквивалентна умножению соответствующих матриц.

Например, поворот точки на 90° в двумерном пространстве задаётся матрицей:

```
R = [[0, -1],
     [1,  0]]
```

Если применить к ней масштабирование S = [[2,0],[0,2]], то совместное преобразование — это просто R·S.

## Системы линейных уравнений

Система линейных уравнений записывается в матричной форме как Ax = b. Решение находится методом обратной матрицы x = A⁻¹·b или через LU-разложение, которое само по себе является последовательностью матричных умножений.

## Собственные значения и собственные векторы

Нахождение собственных значений матрицы A сводится к решению уравнения det(A - λI) = 0. Собственные векторы определяют направления, в которых линейное преобразование действует как простое растяжение. Это понятие лежит в основе метода главных компонент (PCA) и спектрального анализа.
