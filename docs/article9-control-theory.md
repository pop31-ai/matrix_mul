# Теория управления и автоматика

В теории управления матричное умножение описывает динамику систем и проектирование контроллеров.

## 상태 пространство

Линейная динамическая система описывается уравнениями:

```
dx/dt = A·x + B·u
y = C·x + D·u
```

Где A, B, C, D — матрицы, x — вектор состояния, u — вход, y — выход. Матрица A определяет свободную динамику системы, B — как вход влияет на состояние.

## Матрица chuyển trạng thái

Решение системы — это x(t) = e^(At)·x(0), где e^(At) — матричная экспонента. Она вычисляется через ряд Тейлора или разложение Паде, и каждый член ряда — это умножение матриц.

## Контроллеры

В методе полного состояния (state feedback) управление u = -K·x, где K — матрица коэффициентов усиления. Выбор K — это задача размещения собственных значений, которая решается через уравнение Рикатти.

## Наблюдатель Калмана

Фильтр Калмана — это рекурсивный алгоритм оценки состояния системы. На каждом шаге выполняется несколько матричных умножений: предсказание ковариации, вычисление коэффициента Калмана, коррекция оценки.

Фильтр Калмана используется в навигации (GPS/INS), робототехнике, обработке видео и десятках других областей.
