# Как устроено умножение матриц

Алгоритм классического умножения матриц имеет сложность O(n³). Для каждой ячейки результата `C[i][j]` вычисляется сумма произведений элементов i-й строки первой матрицы и j-го столбца второй матрицы.

```
C[i][j] = Σ A[i][k] * B[k][j]  для k от 0 до cols_a-1
```

Ключевое условие: число столбцов первой матрицы должно совпадать с числом строк второй. Если A — размера m×n, а B — размера n×p, то результат C будет размера m×p.

В `matrix_mul.py` проверка совместимости размеров выполняется перед вычислением, а при ошибке выводится понятное сообщение с указанием несовместимых размеров.
