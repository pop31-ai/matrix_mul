# Интерактивный режим и пайпинг

`matrix_mul.py` поддерживает три способа ввода данных:

1. **Прямые аргументы** — каждая матрица передаётся отдельным аргументом командной строки.
2. **Интерактивный режим** (`-i`) — скрипт запрашивает матрицы по очереди, пустая строка завершает ввод.
3. **Пайпинг** — данные можно передать через stdin, что удобно для автоматизации.

**Пример пайпа:**

```bash
echo "[[1,2],[3,4]] [[5,6],[7,8]]" | python matrix_mul.py
```

**Пример интерактивного режима:**

```bash
python matrix_mul.py -i
# Вводите матрицы по одной (JSON-массив). Пустая строка — завершить ввод:
# [[1,2],[3,4]]
# [[5,6],[7,8]]
```

**Результат:**

```
19  22
43  50
```
