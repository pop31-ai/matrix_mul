# Основы умножения матриц

Умножение матриц — это.binary operation над двумя матрицами, результатом которой является новая матрица. Операция была введена в математику Артуром Кэли в 1858 году, хотя аналогичные вычисления использовались значительно раньше.

## Определение

Для двух матриц A размера m×n и B размера n×p их произведение C = A·B определяется как матрица размера m×p, где каждый элемент вычисляется по формуле:

```
C[i][j] = Σ(k=1..n) A[i][k] · B[k][j]
```

То есть элемент в i-й строке и j-м столбце результата — это скалярное произведение i-й строки матрицы A на j-й столбец матрицы B.

## Ключевые свойства

- **Ассоциативность**: (A·B)·C = A·(B·C)
- **Дистрибутивность**: A·(B+C) = A·B + A·C
- **НЕ коммутативность**: A·B ≠ B·B в общем случае

Последнее свойство особенно важно: порядок сомножителей принципиален. Это отличает матричное умножение от обычного умножения чисел.

## Условие корректности

Число столбцов первой матрицы обязательно должно совпадать с числом строк второй. Если A — матрица m×n, а B — матрица n×p, то результат C будет матрицей m×p. Это фундаментальное ограничение определяет, какие матрицы вообще можно перемножать.
