Статья 1. Зачем нужен CLI для умножения матриц

Умножение матриц — одна из базовых операций линейной алгебры. Она используется в computer vision, машинном обучении, 3D-графике и обработке данных. Python-скрипт matrix_mul.py позволяет выполнять эту операцию прямо из терминала без установки тяжёлых библиотек вроде NumPy.

Формат входных данных — JSON-массивы: [[1,2],[3,4]]. Это универсальный формат, который легко генерировать из любого языка программирования. Результат выводится в виде выровненной таблицы чисел.

Пример:
python matrix_mul.py "[[1,2],[3,4]]" "[[5,6],[7,8]]"

Результат:
19  22
43  50


Статья 2. Как устроено умножение матриц

Алгоритм классического умножения матриц имеет сложность O(n³). Для каждой ячейки результата C[i][j] вычисляется сумма произведений элементов i-й строки первой матрицы и j-го столбца второй матрицы.

C[i][j] = Σ A[i][k] * B[k][j] для k от 0 до cols_a-1

Ключевое условие: число столбцов первой матрицы должно совпадать с числом строк второй. Если A — размера m×n, а B — размера n×p, то результат C будет размера m×p.

В matrix_mul.py проверка совместимости размеров выполняется перед вычислением, а при ошибке выводится понятное сообщение с указанием несовместимых размеров.


Статья 3. Интерактивный режим и пайпинг

matrix_mul.py поддерживает три способа ввода данных:

1. Прямые аргументы — каждая матрица передаётся отдельным аргументом командной строки.
2. Интерактивный режим (-i) — скрипт запрашивает матрицы по очереди, пустая строка завершает ввод.
3. Пайпинг — данные можно передать через stdin, что удобно для автоматизации.

Пример пайпа:
echo "[[1,2],[3,4]] [[5,6],[7,8]]" | python matrix_mul.py

Пример интерактивного режима:
python matrix_mul.py -i
Вводите матрицы по одной (JSON-массив). Пустая строка — завершить ввод:
[[1,2],[3,4]]
[[5,6],[7,8]]

Результат:
19  22
43  50


Статья 4. Производительность и ограничения

Скрипт написан на чистом Python без внешних зависимостей. Это делает его максимально портативным, но ограничивает производительность на больших матрицах.

Для матриц размером до 100×100 скрипт работает за миллисекунды. Для матриц 1000×1000 и более следует рассмотреть NumPy или специализированные библиотеки, которые используют SIMD-инструкции и параллелизм.

Ограничения:
- Нет поддержки разреженных матриц
- Нет оптимизации кэширования строк
- Все элементы — числа с плавающей запятой (float)

Для продакшн-сценариев matrix_mul.py подходит как прототип или инструмент для быстрых проверок.


Статья 5. Расширение функционала

matrix_mul.py легко расширить. Вот несколько идей:

1. Поддержка возведения матрицы в степень — matrix_mul.py "[[1,2],[3,4]]" --pow 3
2. Транспонирование — matrix_mul.py "[[1,2],[3,4]]" --transpose
3. Определитель — matrix_mul.py "[[1,2],[3,4]]" --det
4. Обратная матрица — matrix_mul.py "[[1,2],[3,4]]" --inverse
5. Чтение из файла — matrix_mul.py --file matrix.json

Каждое из этих расширений добавляется минимальными изменениями в основной скрипт. Формат JSON-входа остаётся единым, что делает инструмент консистентным.
