# Компьютерная графика и 3D-моделирование

В компьютерной графике матричное умножение используется повсеместно. Каждый кадр, который вы видите на экране — от игр до фильмов — проходит через цепочку матричных преобразований.

## Трансформации объектов

Все пространственные преобразования 3D-объектов — перемещение, поворот, масштабирование — represented матрицами 4×4. Объект с вершинами, заданными координатами, преобразуется умножением на матрицу трансформации.

```
M_итог = M_масштаб · M_поворот · M_перемещение
```

Комбинирование нескольких преобразований — это просто последовательное умножение матриц. Это позволяет за одно умножение применить все трансформации сразу.

## Матрица проекции

Для отображения 3D-сцены на 2D-экран используется матрица проекции. Она переводит трёхмерные координаты в двухмерные, учитывая перспективу. Умножение вектора позиции на матрицу проекции даёт координаты на экране.

## Кинематика роботов

В робототехнике цепочки матричных умножений описывают положение каждого звена робота относительно предыдущего. Матрица Денавита-Хартенберга (DH-параметры) для каждого сочленения умножается на следующую, давая итоговое положение захвата относительно основания.
