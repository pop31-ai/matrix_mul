# Машинное обучение и нейронные сети

Умножение матриц — это вычислительное ядро современного машинного обучения. Все нейросети, от простых перцептронов до трансформеров, построены на матричных операциях.

## Полносвязные слои

В полносвязном (fully connected) слое нейросети каждый нейрон связан со всеми нейронами предыдущего слоя. Вычисление выхода слоя — это умножение матрицы весов W на вектор входов x:

```
y = W·x + b
```

Где W — матрица размера (количество_нейронов_текущего × количество_нейронов_предыдущего), x — вектор входов, b — вектор смещений.

## Свёрточные нейросети

Хотя свёрточные слои (CNN) формально не являются матричными умножениями, на практике они сводятся к ним через им2col — преобразование, которое разворачивает окна свёртки в столбцы матрицы. После этого свёртка становится обычным матричным умножением.

## Трансформеры

Архитектура Transformer, которая лежит в основе GPT и других больших языковых моделей, строится на механизмe внимания (attention). Ядро attention — это умножение матриц Query·Key^T, за которым следует softmax и умножение на Value.

```
Attention(Q, K, V) = softmax(Q·K^T / √d_k) · V
```

Именно поэтому GPU с их массово-параллельными матричными умножениями стали основой для обучения нейросетей.
